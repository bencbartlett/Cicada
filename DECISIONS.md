# Decisions ledger

Locked choices, with dates and rationale. Follow the wall-project
discipline: one row per decision, revise explicitly, never silently.

| Date | Decision | Rationale |
|---|---|---|
| 2026-08-11 | Name: **Cicada**; releases use plain semantic versioning (v0.1, v0.2, …) | Versions should communicate scope and compatibility, nothing else; no themed release names |
| 2026-08-11 | **Code is the source of truth; the graph is a generated view** | The wall project's .gh audit found production code drifted 74 lines behind disk and one module existing *only* inside the binary blob — the graph-as-truth failure mode in its purest form |
| 2026-08-11 | **Two-layer file format**: top layer = restricted dataflow dialect (one binding per node, order-independent), node bodies = arbitrary code the canvas never renders; layout metadata in a sidecar the differ ignores | The Enso/Luna lesson: bidirectional mapping over an arbitrary language collapses into "IDE with extra steps"; a restricted top layer keeps the graph view faithful by construction |
| 2026-08-11 | **Shape/rank-typed wires with named axes** (`Curve` vs `[Curve]` vs `parts: Curve`); broadcasting only via explicit combinators (`map`, strict `zip`, `cross`, `flatten`, `nest`, `transpose`, …; doc 09); element nulls are typed (`Optional`) and slot-preserving | Grasshopper's tree matching + Item/List access caused every worst bug in the wall project; typed shapes make them compile errors ("red wire before anything solves") |
| 2026-08-11 | **Engine in Rust** — data model, geometry, type checker, scheduler, and stdlib nodes are one Rust core; **Python stays available at the script boundary** (subprocess pool, typed marshalling) | A GH-style stdlib invites fine-grained graphs (hundreds of nodes × thousands of elements) where Python's per-element dispatch, boxing, and GIL tax the interactive loop by whole seconds; Rust delivers the stated priorities (speed, parallelism with real cancellation, ADTs, compile-time checking, wgpu GPU path). Revises the v1-runtime-is-Python row, which assumed coarse kernel-dominated stages |
| 2026-08-11 | **Scheduler contract**: content-hash caching per node, minimal recompute, parallel topological execution, disk-persistent memoization, cancellation everywhere, progress + ETA | "Feel-fast" is runtime architecture; GH re-solves everything downstream on a single-threaded UI thread with no cancel — the actually-antiquated part |
| 2026-08-11 | **Script node mechanism**: the function signature IS the ports; docstring first line = node title; re-parse on save; signature changes turn stale wires into type errors, never silent deletions | GH dropping wires on parameter edits is one of its worst behaviors |
| 2026-08-11 | **AI provenance + verification**: AI-written nodes store their generating prompt; nodes may carry property tests; the canvas renders red when a contract fails on current data | Turns "vibe-coded" into "vibe-coded but continuously verified"; keeps the human's mid-level understanding intact |
| 2026-08-11 | **Rent all geometry kernels** behind one typed seam: Manifold via `manifold3d` (mesh booleans), spade/delaunator (Voronoi/Delaunay), OCCT via `opencascade-rs` (B-rep + STEP, v0.2), fidget (implicits; supersedes libfive), ttf-parser/rustybuzz (text outlines), glam/curvo/lyon/cavalier_contours (vectors, NURBS, 2D paths/offsets). Optional rescue backend: Rhino.Compute | Kernel robustness is decades of accumulated case-handling (SSI, tolerant topology, fillets); Parasolid is $30–100k+/yr and company-only; OCCT is free with known ceilings; per-op routing keeps no single kernel's failure modes owning the pipeline |
| 2026-08-11 | **UI stack: Tauri shell (Rust core in-process) + customized React Flow canvas + three.js viewport**; instanced rendering; display is a first-class edge with visible cost; backward picking (click geometry → node + element index) is a launch requirement, not polish; native wgpu viewer is the v2 escape hatch | The web canvas ecosystem is the only mature node-editor substrate — GH-grade polish is rentable there; one docked window beats the GH/Rhino split; backward picking + tap-any-wire-to-preview are most of why node UIs feel good. Supersedes polyscope, which was chosen for the all-Python stack |
| 2026-08-11 | **Blender is the photorealistic render backend**, bridged via USD (attributes carry ids/axes/material bins), driven headless via `pip install bpy` (Cycles) | Don't build rendering twice; Cicada owns the fast preview, Blender owns beauty shots |
| 2026-08-11 | **Test corpus = the wall-piece pipeline** (field solver, colorizer, labels, pins, carve, packer, exporters) | Real 1,500-part production code with known bodies buried; porting it is the empirical answer to every performance claim |
| 2026-08-11 | **Deferred, explicitly**: 2D constraint sketcher (rent planegcs/SolveSpace's solver when needed), GH plugin-ecosystem parity, Class-A NURBS surfacing, native wgpu viewer | Scope discipline: the unbounded tail is editor polish and kernel parity; neither blocks the thesis |
| 2026-08-11 | **Editable canvas ships in v1**: GH-style drag-and-drop placement, wiring, and parameter editing; every canvas edit materializes as a text edit to the dialect layer | Bidirectional editing is safe over a restricted one-binding-per-node dialect — the Enso trap requires an arbitrary language. GH migrants need direct manipulation on day one; revises the read-only-canvas deferral |
| 2026-08-11 | **Data model: sum types + capability traits + refinement wrappers** (`Closed<Curve>`, `Planar<Curve>`); the wire-compatibility lattice (Circle <: Curve <: Geometry) lives in the checker, not host-language inheritance; generics are kind-preserving (Move: T → T) | Closedness/planarity are data-dependent properties, so they are checked refinements entered via explicit conversions (red with offending IDs on failure), not subclasses; exhaustive enum matching forces every stdlib node to handle or explicitly reject every kind |
| 2026-08-11 | **Stdlib = ~130 macro-registered typed node functions** cloning GH's most-used set (docs/08); pure, deterministic, explicit seeds; the registry serializes to a JSON catalog driving the palette, the checker, and the AI | Signature-is-the-ports extended to the stdlib at compile time; the catalog is the machine-readable surface the AI composes from |
| 2026-08-11 | **User code in two tiers, ports auto-derived in both** (revises the three-tier row — the lowered-Python transform tier is dropped): (1) Expression nodes — language-neutral math syntax (`z = x^2 + y^2`), free variables become input ports, the assignment target names the output; (2) script nodes in sibling files — **Rust by default, including AI-generated nodes**, compiled to sandboxed WASM (wasmtime: epoch preemption = hard cancellation; a crash costs one node); a **Python 3 script node** (full CPython subprocess, numpy/scipy/rhino3dm) exists like Grasshopper's | One language for the core — commit to Rust; Python remains an option at the edges, never in the core representation |
| 2026-08-11 | **GH tree vocabulary retired**: lists are lists (`[T]`, `[[T]]`); graft/flatten/simplify/Path Mapper replaced by standard typed combinators (`map`, strict `zip`, `cross`, `flatten`, `nest`, `squeeze`, `transpose`, `chunk`, `group_by`, `compact`); zip length-mismatch is an error with opt-in policies (`pad_last`, `cycle`, `truncate`) | The tree/graft/branch model is GH's most-documented pain point (doc 09); standard programming terms transfer, positional path voodoo doesn't |
| 2026-08-11 | **Wiring is type-gated in the UI**: incompatible connections cannot be completed (blocked at drag, with a reason); liftable mismatches connect only through a recorded adapter chip; lifted ports wear persistent iteration badges (`map ×depth`, `zip`) and wire hover shows the exact pairing | "Red wire before anything solves" moved earlier still: the wrong wire never exists, and iteration is always visible, never guessed |
| 2026-08-11 | **Pipeline file = `.cic`, Cicada's own minimal dialect** — bindings and expressions only; all multi-statement code lives in script files; version pragma `# cicada 1`; tree-sitter grammar + editor extension ship with v0.1; layout in `name.cic.layout.json`; cache and lock local-only; `.ci` rejected (collides with continuous-integration conventions) | Commit to one core language instead of aping Python (revises the `.ci.py` choice); the grammar is tiny enough that first-party tooling beats borrowed highlighting; a Rust-source file was rejected on semantics, not syntax — the dialect needs forward references, `^` as power, axis annotations, and domain-quality wire errors rather than rustc trait diagnostics; named arguments come from the struct-in/struct-out ABI (doc 10) |
| 2026-08-11 | **Dialect grammar rules**: single assignment (names are node identity); one node call per binding — nested calls are "name the intermediate" errors; **all arguments are kwargs**, each marked required or optional — positional args are parse errors; canvas port display order is a sidecar UI mapping, never code; `each(arg)` is the textual form of the lift chip (multiple `each` = strict zip); params are constructor bindings (`slider`/`toggle`/`choice`/bare literals); operator RHS = one Expression node (`^` = power); axis renames via binding annotation (`cells: parts = …`) | Every node nameable, inspectable, cacheable; lifts and pairings visible in text forever; every port is labeled in the UI, so positional args buy nothing (doc 10) |
| 2026-08-11 | **Round-trip writer discipline**: every canvas gesture maps to a specified minimal text edit (slider drag = one numeric token); the writer never reformats, reorders, or realigns existing lines; deleting a node produces red unknown-name errors downstream, never cascade deletion; rename updates references + sidecar atomically; caches key on content hashes so renames never recompute | Small reviewable diffs are the product; GH's silent wire-dropping inverted into loud, local errors (doc 10) |
| 2026-08-11 | **Git integration is first-class UI**: status strip with per-node change markers, node-level visual graph diff (a rendering of the text diff — it can never disagree with `git diff`), commit from the app, per-node history; plain git underneath, no custom store | One-binding-per-line + the minimal-edit writer make line diffs = node diffs; determinism makes artifact diffs meaningful; diffability is a product feature, not a byproduct (doc 10) |
| 2026-08-11 | **Auto-layout-first sidecar on a unit grid**: deterministic, snappy auto-layout; the sidecar stores manual overrides only (integer grid cells; one unit = the port-row pitch; node sizes are integer units; movement grid-snapped — no alignment tools needed); deleting an override snaps back to auto; port display order is a sidecar mapping | Untouched nodes carry zero layout state, so the sidecar stays near-empty and near-auto by construction; grid-snap revisable if it chafes (doc 10) |
| 2026-08-11 | **Node ABI is struct-in/struct-out**: every node function takes one input struct with named fields and returns an output struct with named fields (bare return allowed for single-output nodes; port named `out`); `#[derive(Ports)]` + `#[node]` reflect fields → ports; optional port = field with a default; the same field names appear in Rust call sites, the JSON catalog, the canvas labels, and dialect kwargs | Rust has no keyword arguments for functions — input structs are how it gets them; one nomenclature end to end kills a whole class of mapping bugs; Python script nodes mirror the ABI with dataclasses (docs/08) |
| 2026-08-11 | **AI edit loop**: agents edit the pipeline text directly; order-independence means no insertion constraints (append anywhere; `fmt` beautifies); the checker is the inner loop — milliseconds, no solve, JSON diagnostics with suggested fixes; read tools ground agents in live graph state (what-feeds, wire summaries, catalog search, profiler); mechanical bulk changes go through AST-safe refactor primitives (rename, insert_between, extract_script — the same ops the canvas uses); edits land as git diffs with guarded tiers (deletes, renames, rewires, param values); exports never run without explicit human action | The dialect's restrictions are exactly what make agent edits cheap and safe — local semantics, unambiguous references, machine-checkable in milliseconds (doc 11) |
